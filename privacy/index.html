章厂 Pro 隐私政策

发布者：冰咖啡（Partner Center） · 更新日期：2026-11-01 · 适用于 Windows 桌面应用「章厂 Pro」

欢迎使用章厂 Pro（下称「本软件」）。本政策说明我们如何处理与本软件相关的信息。使用本软件即表示你知悉本政策内容。

1. 我们是谁

本软件由发布者「冰咖啡」提供，定位为本地优先的网文/短篇写作生产工具。微软商店产品页可参见： apps.microsoft.com/detail/9NPGTJ0H8368。

2. 我们默认收集什么

首发版本不向我们自有服务器上传你的小说正文、大纲、人物设定或项目文件。 上述内容默认仅保存在你的电脑本地（应用数据目录）。

我们也不会为了「云同步」或「官方模型算力」在首发版强制收集账号画像。若日后增加可选云功能，会先更新本政策并在软件内提示你选择开启。

3. 本机存储的信息

  • 项目、大纲、章节、短篇稿件等写作数据（本地数据库）
  • 你在设置中填写的第三方模型 API Key（明文保存在本机，仅本机进程读取；请自行保管电脑安全）
  • 试用开始时间、激活/许可状态等许可相关元数据（本地）
  • 软件偏好设置（如所选模型服务商）

4. 网络请求会发往哪里

当你开启 AI 生成/审核等功能并配置了 API Key 时，本软件会把生成所需的提示与上下文直接发送到你所选择的第三方模型服务（例如 DeepSeek、或其他你自行填写的兼容接口），而不是先经过我们的服务器。

这些第三方如何处理数据，以其各自的隐私政策与服务条款为准。你可以随时在设置中删除 Key、关闭联网生成，或在防火墙中限制本软件联网。

安装、更新若通过微软商店进行，微软可能按其商店政策处理下载与许可相关信息；详见微软隐私声明。

5. 我们不拿你的稿件做什么

  • 不用你的正文训练我们自己的模型（首发我们也不运营自有模型服务）
  • 不出售你的稿件或项目数据
  • 不把本地稿件用于广告定向

6. 权限说明

本软件需要访问网络（仅在你使用需联网的功能时，例如调用第三方模型 API），以及读写本机文件/应用数据目录以保存项目。我们不会申请与功能无关的敏感权限。

7. 儿童

本软件面向一般写作用户，不以儿童为主要服务对象。若你是监护人并认为未成年人使用了本软件，请联系我们，我们将配合处理合理请求。

8. 数据删除与卸载

卸载本软件通常会移除程序文件；本地用户数据目录中的项目库可能仍保留在本机。你可手动删除对应用户数据文件夹以清除本地稿件与 Key。删除后无法由我们从云端恢复（因为默认无云端副本）。

9. 政策变更

若功能变化导致数据处理方式实质变更（例如增加可选云同步或官方 API），我们会更新本页「更新日期」，并尽量在软件内提示。请以本页最新版本为准。
